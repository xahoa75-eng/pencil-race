# Pencil Race

La course au crayon de la cour de récré, sur téléphone. 8 voitures à pouvoirs, 8 circuits dessinés au crayon sur papier à carreaux, solo contre des bots et multi à 2–4 joueurs.

Jeu : ouvrir `index.html` dans un navigateur (ou le site GitHub Pages du dépôt).
Développement : voir `CLAUDE.md`.
